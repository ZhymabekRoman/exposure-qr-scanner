# Exposure QR Scanner (Android)

A lightweight, modern, open-source Android QR and barcode scanner designed specifically for difficult scanning conditions (glare, OLED/monitor displays, dark rooms, blown-out backlights) with full manual **Exposure Compensation (EV)** control.

## Key Features
- **CameraX + Live Exposure Slider**: Interactive on-screen slider (`-EV` to `+EV`) to control camera exposure compensation in real time.
- **Fast QR/Barcode Decoding**: Instant detection on live camera frames.
- **Privacy First / Offline**: Works 100% offline, zero trackers, no unnecessary permissions.
- **Torch & Zoom Support**: Standard flashlight toggle and pinch-to-zoom alongside exposure tuning.
